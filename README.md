# Projeto-final
Projeto de um E-comerce desenvolvido em Vue 3 + pinia, esse projeto foi realizado durante o curso de formação em Front-end no Instituto 3C, foi um projeto final, que consumiu uma API REST fornecida pelo instrutor do curso, com foco em integração, manipulação de dados e exibição dinâmica no cliente.



## Project Setup

```sh
npm install
```


### Compile and Minify for Production

```sh
npm run build
```
